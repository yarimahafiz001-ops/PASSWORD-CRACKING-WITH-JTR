# Password Cracking with John the Ripper (JTR)

## Cybersecurity & Ethical Hacking Lab

### Project Overview

This project demonstrates an authorized cybersecurity laboratory exercise focused on password recovery from an encrypted PDF using **John the Ripper (JTR)** and the **Johnny graphical user interface** on Windows.

The exercise was performed in a controlled learning environment for cybersecurity and ethical hacking practice.

## Objectives

- Understand password-protected PDF security.
- Install and configure John the Ripper.
- Configure the Johnny GUI to use the JTR executable.
- Extract a PDF password hash for the authorized lab file.
- Load the hash into Johnny.
- Perform password recovery using John the Ripper.
- Document the cybersecurity testing process.

## Tools Used

- John the Ripper (JTR)
- Johnny GUI
- Windows
- Online PDF hash extraction tool
- Notepad

## Methodology

### 1. John the Ripper Installation

John the Ripper was downloaded and extracted on a Windows computer.

The JTR executable was located inside the `run` directory.

### 2. Johnny GUI Configuration

Johnny was installed and configured to use the John the Ripper executable.

The configured executable was:

`john.exe`

### 3. PDF Hash Extraction

The authorized encrypted PDF was processed using a PDF hash extraction tool.

The resulting PDF hash was obtained in a format compatible with John the Ripper.

### 4. Hash File Preparation

The extracted hash was saved in a text file:

`hash1.txt`

This file was then loaded into Johnny.

### 5. Password Recovery

Johnny was used to start a password recovery attack against the authorized lab hash.

The recovered password was then used to verify access to the protected training PDF.

## Result

The laboratory exercise successfully demonstrated the password recovery workflow for an authorized encrypted PDF.

The recovered credential is intentionally **not published in this repository**.

## Security Lessons Learned

This exercise demonstrated:

- The importance of strong passwords.
- The risks associated with weak or predictable passwords.
- How password hashes can be used during security assessments.
- How security professionals can test password strength.
- The importance of authorization when performing password recovery activities.

## Ethical Considerations

This project was performed for authorized cybersecurity education and laboratory practice.

John the Ripper should only be used against passwords, hashes, files, or systems that you own or have explicit permission to test.
